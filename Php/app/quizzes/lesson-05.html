  1. Start ($i = 0) — runs once, at the beginning. Condition ($i < 4) — runs before every round; if false, the loop stops. Step ($i++) — runs after every round.

  4. Nothing inside changes $n, so the condition never becomes false: an infinite loop. The terminal or page freezes. Ctrl + C stops it.
