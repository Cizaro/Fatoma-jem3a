✅ Check your answers — open this only when you have finished
  1. Round ( ) = the condition, the question being asked. Curly { } = the code that runs if the answer is yes.
  2. Prints Pass. The bug: PHP stops at the first true branch, and >= 10 catches 19 before it ever reaches >= 18. Conditions must go strictest first.
  3. False: 0, "0", "". True: "hello", -1, "false" (a non-empty string is true).
  4. break; is missing. Without it PHP falls through and prints redyellow.
  5. The ; straight after if (...) ends the statement, so the { } block is no longer attached to the if and runs every time.
  6. php if ($n % 2 == 0) { echo "Even"; } else { echo "Odd"; }
  7. >= 18, >= 16, >= 14, >= 10 — biggest first, because PHP takes the first true one.
  8. Use switch when you compare one variable against several exact values. Use if for ranges like >= 10.
