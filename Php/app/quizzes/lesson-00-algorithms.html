6. Any pseudocode with these four ideas, for example:

Input M1, M2
AVG <-- (M1 + M2) / 2
if (AVG >= 50) then
    Print "PASS"
else
    Print "FAIL"
endif

Marks are for: reading both marks, the arrow assignment, the condition the right way round, and both branches. Note >= 50 and < 50 are both correct here, as long as the PASS and FAIL are on the matching sides.
