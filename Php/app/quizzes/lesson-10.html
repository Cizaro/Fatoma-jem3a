  1. A static page shows everyone the same thing. A dynamic page builds itself from the database every time it's opened — change a row, refresh, the page changed.
  2. include gives a warning and carries on if the file is missing. require stops the page completely. Use require for anything the page can't live without.
  3. So it's written once and used by every page. Change the menu in one file and every page updates.
  4. $id = (int)($_GET["id"] ?? 0); The (int) forces it to a number, so ?id=abc or an injection attempt becomes a harmless 0 instead of reaching your query.
  5. In the PHP variable: $term = "%" . $search . "%"; The SQL itself only ever contains ? — that's what keeps the statement safe.
  6. A friendly "nothing found" message. A blank page makes the user think the site is broken.
  7. header() tells the browser to go to another page; exit stops the rest of the script from running. Together they also stop a refresh from saving the same thing twice.
  8. Any four: prepared statements for every user value · htmlspecialchars() on every printed value · (int) on every id from a URL · a friendly empty-result message · redirect after saving · close the connection at the end.
