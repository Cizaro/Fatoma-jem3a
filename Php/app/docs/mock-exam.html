Section 3 - Code Output and Tracing

Write the EXACT output. Spaces matter. 12 marks, about 17 minutes.

1. What is printed?

<?php
$a = "5";
$b = 5;
var_dump($a == $b);
var_dump($a === $b);

2. What is printed?

<?php
for ($i = 1; $i <= 6; $i++) {
    if ($i % 2 == 0) continue;
    if ($i == 5) break;
    echo $i . " ";
}

3. What is printed?

<?php
$n = 10;
do {
    echo "run ";
    $n++;
} while ($n < 5);

4. What is printed?

<?php
$s = "PHP";
$s .= " is";
$s .= " fun";
echo $s . " (" . strlen($s) . ")";

5. What is printed?

<?php
$cart = ["pen" => 3, "book" => 12, "bag" => 25];
$t = 0;
foreach ($cart as $item => $price) {
    if ($price < 5) continue;
    $t += $price;
}
echo $t;

6. What is printed?

<?php
$x = 10;
$y = $x++;
$z = ++$x;
echo "$x $y $z";

7. This script has three faults. Name each one and give the correction.

<?php
$price = 10
$qty = "3";
if ($price = 10) {
    echo "Total: " + $price * $qty;
}

Section 4 - Main Algorithmic and Coding Exercise

20 marks, about 25 minutes. All three deliverables are required.

A tutor types five marks out of 20 into a form, one box per student, and presses Show results. The page must then display a table of the five marks with a letter grade beside each one, and underneath it the total, the average to two decimal places, the highest mark, and how many students passed (a pass is 10 or more). If any box is empty or holds something that is not a number from 0 to 20, the page must say so and show no table.

Grades: 18 and over = A | 16 = B | 14 = C | 10 = D | under 10 = F

(a) Pseudocode - 5 marks

(b) Flowchart - 5 marks, showing the inputs, the decisions and the loop

(c) PHP code - 10 marks, with inline // comments and a PHPDoc block (/** ... */)
