Lesson 03 — the Exercise

Circle Area and Sphere Volume Calculator

Write PHP code to calculate the surface area of a circle (A = π·r²) and the volume of a sphere (V = ⁴⁄₃·π·r³) using a given radius (r). You will implement this solution using two different approaches.

Part 1 — Static / Developer-Defined

  • A script named part1_static.php
  • A variable $radius with a hardcoded value (e.g. $radius = 5)
  • Calculate the circle area and the sphere volume
  • Display the radius with both results rounded to 2 decimal places

Part 2 — Dynamic, using an HTML Form

  • An index.html with a form: an <input type="number"> with step="any" for the radius, and a submit button
  • The form submits by POST to part2_dynamic.php
  • part2_dynamic.php must: - check the form was submitted via POST - validate that the radius is set and is a positive number - compute both values from the user's input - display a clean output, or an error message if the input is invalid or empty

Those four bullets in Part 2 are a marking scheme. Submitted check, validation, computation, error message. Section 4 asks for the same four things whatever the scenario.

⭐ Problem 5 — The Cloud Storage Pricing Tier Generator

Write a PHP script that loops through node counts from 1 to 6.

  • Runs automatically on page load.
  • For each node step, calculate 10 × N (Storage GB), 100 × N

(Bandwidth TB) and 1000 × N (API Requests).

  • Output the results inside an HTML5 <table>.

Same shape as Problem 4 with three computed columns instead of two. Do it straight after, from blank, without looking back.

Boundary again: 1 to 6 is six rows.

The thing both table problems are teaching

Everything that happens once goes outside the loop — <table>, the heading <tr>, </table>. Everything that happens per row goes inside — and that is only ever one <tr>…</tr>.

Putting the heading row inside the loop is the commonest mistake in a table question, and it is instantly visible in the output: six heading rows.
