# 🎮 Syntax Stages — the pure beginner track

**Start here if the lessons feel too fast.**

The lessons in `01-basics/` onwards teach you *ideas*. This folder teaches you **the typing** —
the brackets, the dollar signs, the semicolons — in the smallest steps that exist.

**30 stages. 6 worlds. Each stage is 3–5 minutes.**

You don't have to understand *why* yet. You just have to get the line to run. Understanding
arrives on its own once your fingers stop fighting you.

## How a stage works

Every stage has exactly four parts:

1. **🎯 Goal** — the one thing this stage teaches. One thing. Never two.
2. **⌨️ The syntax** — the shape to copy.
3. **✅ Clear the stage** — a tiny task. Type it, run it, see it work.
4. **💀 If it breaks** — the error you'll probably get, and what it means.

**The rule: type it, don't paste it.** Your hands have to learn where the `$` and the `;` live.
Copy-pasting teaches your clipboard, not you.

---

## How to run a stage

Open a terminal in the `Php` folder. Each world has one practice file:

```bash
php stages/practice/world-1.php
```

Write your answer in that file, save, run it again. That loop — edit, save, run — is
what programming actually is.
